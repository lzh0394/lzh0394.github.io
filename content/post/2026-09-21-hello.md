## 结构

整站只有几个需要你关心的路径：

```bash
content/post/       # 文章都放这里
content/about.md    # 「关于」页面
hugo.yaml           # 所有配置都在这个文件里
themes/hugo-xmin/   # 主题，总共约 140 行代码
```

Hugo 会扫描 `content/`，套上 `themes/hugo-xmin/` 里的模板，输出静态文件到 `public/`。

## 常用命令

```bash
# 本地预览，改文件会自动刷新
hugo server --buildDrafts

# 构建生产版本（跳过 draft: true 的文章）
hugo

# 新建文章
hugo new content post/2026-09-22-hello.md
```

## 一篇新文章的头部

每篇文章开头的 `---` 之间是元数据，Hugo 称之为 front matter：

```yaml
---
title: "文章标题"
date: 2026-09-22
categories: ["随笔"]
tags: ["标签一", "标签二"]
draft: false
---
```

`draft: true` 的文章**不会**出现在正式构建里，只有加 `--buildDrafts` 本地预览才看得到。写完准备发布时把它改成 `false` 即可。

## 引用与列表

> 极简不是把东西删到不能再删，而是删到不能再删之后，剩下的每一样都有理由。

- 想加评论，可以接 Giscus（基于 GitHub Discussions），在 `themes/hugo-xmin/layouts/_partials/foot_custom.html` 里放一段脚本即可
- 想加搜索，xmin 本身没有内置，需要自己接 [Pagefind](https://pagefind.app/)
- 想加访问统计，可以在同一个 `foot_custom.html` 里放统计脚本

但说实话，如果你需要上面这些，说明你想要的可能已经不是一个"极简"博客了——这不是问题，只是要想清楚。
