《抽象代数 III——交换代数》由孟道骥、王立云、袁腊梅编著，科学出版社 2016 年出版。全书由引论与七章组成，主题依次为交换环的根和根式理想、模、分式环与分式模、诺特环、整相关性与 Dedekind 整环、完备化与维数理论、赋值域。

交换代数与代数数论、代数几何有直接联系：代数整数环是 Dedekind 整环的原型，代数簇的坐标环是有限生成约化代数，局部化与完备化则是研究这两类对象的共同工具。

## 0. 引论

引论用两个来源说明交换代数的问题意识。代数数论一侧从代数数与代数整数出发，代数几何一侧从代数簇出发，随后补充模、范畴与函子、Zorn 引理等工具。

| 节 | 内容 |
| --- | --- |
| 0.1 | 代数数与代数整数 |
| 0.2 | 代数簇 |
| 0.3 | 模 |
| 0.4 | 范畴与函子 |
| 0.5 | Zorn 引理 |

- 代数整数环对加法、乘法封闭，但不一定唯一分解，这一缺陷推动理想理论。
- 代数簇的坐标环把几何对象转成环，环的同态对应簇的态射。
- Zorn 引理保证极大理想存在，是后续多个存在性定理的基础。

---

## 1. 交换环的根和根式理想

本章复习并深化交换环的基础。理想的运算、素理想与极大理想之后，引入根与根式理想，为局部化与准素分解做准备。

| 节 | 内容 |
| --- | --- |
| 1.1 | 环的基本概念 |
| 1.2 | 同态与同构 |
| 1.3 | 理想的运算 |
| 1.4 | 素理想与极大理想 |
| 1.5 | 根与根式理想 |

- 环的根刻画幂零元，根式理想等于自身根的理想。
- 素理想链的长度给出 Krull 维数，极大理想对应域上的商环。
- 理想的根与准素理想是第 3、4 章分解理论的预备。

## 2. 模

本章把模论提升到同调语言。正合序列、张量积、投射模与内射模依次出现，纯量的限制与扩充处理环变换，最后一节讨论代数及其张量积。

| 节 | 内容 |
| --- | --- |
| 2.1 | 模及其同态 |
| 2.2 | 自由模与模的直和 |
| 2.3 | 模的正合序列 |
| 2.4 | 模的张量积 |
| 2.5 | 张量积的正合性 |
| 2.6 | 投射模与内射模 |
| 2.7 | 纯量的限制与扩充 |
| 2.8 | 代数及其张量积 |

- 张量积对右变元右正合，平坦模使张量积保持正合。
- 投射模与内射模分别使 `Hom` 函子正合，自由模是投射模的特例。
- 纯量的限制与扩充把不同环上的模互相转化，是基变换的代数形式。

## 3. 分式环与分式模

本章引入局部化。乘法封闭集给出分式环与分式模，局部性说明局部性质可以逐点检验，理想的扩张与局限描述局部化对理想的作用，最后一节给出准素分解。

| 节 | 内容 |
| --- | --- |
| 3.1 | 交换幺环的乘法封闭集 |
| 3.2 | 分式环与分式模 |
| 3.3 | 局部性 |
| 3.4 | 理想的扩张与局限 |
| 3.5 | 准素分解 |

- 局部化把环在乘法封闭集处取分式，素理想处的局部化给出局部环。
- 性质在局部成立则可整体成立，这一原则贯穿第 4 至 6 章。
- 准素分解把理想写成准素理想的交，是唯一析因分解在一般诺特环上的替代。

---

## 4. 诺特环

本章围绕链条件展开。诺特环的升链条件与有限生成理想等价，希尔伯特基定理保证多项式环保持诺特性，诺特环上的理想有准素分解，阿廷环则给出对偶的降链条件。

| 节 | 内容 |
| --- | --- |
| 4.1 | 链条件 |
| 4.2 | 诺特环 |
| 4.3 | 诺特环中的准素分解 |
| 4.4 | 阿廷环 |

- 诺特环满足理想升链条件，等价于每个理想有限生成。
- 希尔伯特基定理说明诺特环上的多项式环仍是诺特环，这是代数几何有限性的基础。
- Lasker–Noether 定理给出诺特环中理想的准素分解，阿廷环满足理想降链条件。

## 5. 整相关性与 Dedekind 整环

本章处理整扩张与理想分解。整相关性、整闭整环之后，用希尔伯特零点定理连接代数与几何，再引入离散赋值环与 Dedekind 整环，最后回到代数整数环。

| 节 | 内容 |
| --- | --- |
| 5.1 | 整相关性 |
| 5.2 | 整闭整环 |
| 5.3 | 希尔伯特零点定理 |
| 5.4 | 离散赋值环 |
| 5.5 | Dedekind 整环 |
| 5.6 | 分式理想 |
| 5.7 | 代数整数环 |

- 整相关性与有限生成模等价，整闭整环在分式域中取整闭包。
- 离散赋值环是维数为 1 的诺特局部整闭整环，Dedekind 整环在每个素理想处的局部化都是离散赋值环。
- Dedekind 整环中每个非零理想唯一分解为素理想的乘积，代数整数环是典型例子。

## 6. 完备化和维数理论

本章引入拓扑工具。滤链给出拓扑与完备化，相伴分次环与希尔伯特函数计算维数，诺特局部环的维数理论给出 Krull 主理想定理，最后一节讨论超越维数与超越数。

| 节 | 内容 |
| --- | --- |
| 6.1 | 拓扑和完备化 |
| 6.2 | 滤链、分次环与分次模 |
| 6.3 | 相伴的分次环 |
| 6.4 | 希尔伯特函数 |
| 6.5 | 诺特局部环的维数理论 |
| 6.6 | 超越维数 |
| 6.7 | 超越数 |

- `I`-进拓扑下的完备化把局部环嵌入形式幂级数环，是研究奇点的工具。
- 希尔伯特函数最终为多项式，其次数给出维数。
- 诺特局部环的维数不超过极大理想的生成元个数，等号情形对应正则局部环；超越维数衡量域扩张的超越程度。

## 7. 赋值域

本章从有序域与绝对值出发，引入赋值与赋值环，讨论非阿氏赋值、代数数域到实数域的赋值，以及代数数域的全部赋值。

| 节 | 内容 |
| --- | --- |
| 7.1 | 有序域及其完备化 |
| 7.2 | 赋值域及其完备化 |
| 7.3 | 非阿氏赋值 |
| 7.4 | 有限代数数域到实数域的赋值 |
| 7.5 | 代数数域的赋值 |

- 赋值把域的元素映射到有序 Abel 群，赋值环由非负元素组成。
- 非阿氏赋值满足强三角不等式，`p`-进绝对值是典型例子。
- 代数数域的素理想与赋值一一对应，乘积公式联系所有赋值。

---

## 8. 读法建议

引论与第 1 章篇幅短，但提供了全书反复使用的例子，不宜跳过。第 2 章的同调语言与第 3 章的局部化是后续章节的工具，建议连续阅读。第 4 章与第 5 章构成理想理论的主线，第 6 章与第 7 章分别从拓扑与分析两个方向补足交换代数的边界。

若目标偏代数数论，第 5 章与第 7 章是重点；若目标偏代数几何，第 4 章至第 6 章是重点。两章之后的习题多涉及具体环的计算，例如代数整数环的素理想分解与局部化后的维数。
