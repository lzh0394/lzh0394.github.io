群论研究对称性。对称性可以来自图形、置换或同余，抽象出来都是同一个结构：集合配上满足结合律、有单位元、有逆元的运算。本章先给三类例子，再建立子群、商群、作用与 Sylow 理论，最后到可解群与自由群。

## 0. 三个来源

### 0.1 正多边形的对称

正 `n` 边形的对称构成二面体群 `D_n`。旋转 `r` 每次转 `2π/n`，生成 `n` 阶循环群；反射 `s` 关于一条对称轴翻转。

`D_n` 共有 `2n` 个元素：`n` 个旋转与 `n` 个反射。生成元满足

```text
r^n = 1,  s^2 = 1,  srs^{-1} = r^{-1}
```

最后一条说明反射把旋转反号。`n = 3` 时 `D_3 ≅ S_3`；`n = 4` 时 `D_4` 是正方形的对称群，阶为 `8`，与四元数群 `Q_8` 不同构。

`n` 为奇数时，每条反射轴过一个顶点与对边中点；`n` 为偶数时，一半的轴过两个相对顶点，另一半过两条相对边的中点。

### 0.2 置换群

`n` 个文字的置换构成对称群 `S_n`，阶为 `n!`。把置换写成轮换的乘积，例如 `(1 2 3)(4 5)` 表示 `1 → 2 → 3 → 1` 与 `4 → 5 → 4`。

不相交轮换的分解在顺序意义下唯一。一个轮换的长度就是它的阶，一般置换的阶是各轮换长度的最小公倍数。

每个置换可以分解为对换的乘积。分解不唯一，但对换个数的奇偶性不变，由此定义符号同态 `sgn: S_n → {±1}`。核是交错群 `A_n`，阶为 `n!/2`（`n ≥ 2`）。

`S_n` 由所有对换生成，也由 `(1 2)` 与 `(1 2 … n)` 生成。生成元越少，验证同态时越省事。

### 0.3 模 n 的剩余类

模 `n` 的剩余类在加法下构成循环群 `Z/nZ`。与 `n` 互素的剩余类在乘法下构成单位群 `(Z/nZ)^×`，阶为 `φ(n)`。

例如 `n = 6` 时，单位群为 `{1, 5}`，同构于 `Z/2Z`；`n = 5` 时，单位群为 `{1, 2, 3, 4}`，同构于 `Z/4Z`。

两类群的区别在于运算：加法群总是交换的，单位群不一定。`(Z/8Z)^× = {1, 3, 5, 7}` 中每个元素的平方都是 `1`，它不同构于 `Z/4Z`。

### 0.4 群的定义

群是集合 `G` 与二元运算 `·`，满足：

- 结合律：`(ab)c = a(bc)`。
- 单位元：存在 `e`，使 `ea = ae = a`。
- 逆元：每个 `a` 存在 `b`，使 `ab = ba = e`。

若运算还满足交换律，称为 Abel 群。群中元素个数称为阶，记作 `|G|`。有限群与无限群的很多结论要分开叙述。

常见的例子包括 `(Z, +)`、`(Q ∖ {0}, ×)`、`GL_n(F)`、`SL_n(F)`、`S_n`、`A_n`、`D_n`。`(N, +)` 没有单位元之外的逆元，`(Z, ×)` 只有 `±1` 可逆，都不是群。

## 1. 子群与循环群

### 1.1 子群判别

子群是 `G` 的非空子集 `H`，在继承的运算下仍是群。判定只需要一条：

`H` 是非空子集，若对任意 `a, b ∈ H` 都有 `ab^{-1} ∈ H`，则 `H` 是子群。

证明分三步。取 `a ∈ H`，由 `aa^{-1} = e ∈ H` 得到单位元；再由 `eb^{-1} = b^{-1} ∈ H` 得到逆元；最后由 `a(b^{-1})^{-1} = ab ∈ H` 得到乘法封闭。

这条判别把「验证四条公理」压缩成「验证一条运算」。子群的交仍是子群，但子群的并不一定是子群。

### 1.2 生成子群

给定子集 `S ⊂ G`，所有包含 `S` 的子群的交仍是子群，称为 `S` 生成的子群，记作 `⟨S⟩`。

`⟨S⟩` 的元素是 `S` 中元素及其逆元的有限乘积。若 `S` 只有一个元素 `g`，得到循环子群 `⟨g⟩`。

几个例子：`⟨2⟩ = 2Z ⊂ Z`；`⟨(1 2), (2 3)⟩ = S_3`；`⟨r⟩ ⊂ D_n` 是旋转子群，阶为 `n`。

### 1.3 循环群

若 `G = ⟨g⟩`，称 `G` 为循环群，`g` 为生成元。循环群的结构完全由生成元的阶决定。

若 `g` 的阶无限，映射 `k ↦ g^k` 给出同构 `Z ≅ ⟨g⟩`。若 `g` 的阶为 `n`，映射 `k mod n ↦ g^k` 给出同构 `Z/nZ ≅ ⟨g⟩`。

证明用带余除法：任意整数 `k` 写成 `qn + r`，于是 `g^k = g^r`，而 `0 ≤ r < n` 时 `g^r` 互不相同。

循环群的子群仍是循环群。`Z` 的子群都是 `nZ`；`Z/nZ` 的子群与 `n` 的正因子一一对应。

复数中的 `n` 次单位根 `μ_n = {z : z^n = 1}` 是 `n` 阶循环群，生成元是本原单位根 `e^{2πi/n}`。

### 1.4 陪集与 Lagrange 定理

设 `H ≤ G`。左陪集是 `gH = {gh : h ∈ H}`。两个左陪集要么相等，要么不交；`gH = g'H` 当且仅当 `g^{-1}g' ∈ H`。

映射 `h ↦ gh` 给出 `H` 与 `gH` 的双射，所以每个陪集与 `H` 等势。陪集的个数称为指数，记作 `[G:H]`。

Lagrange 定理：

```text
|G| = |H| · [G:H]
```

证明只用一件事：左陪集构成 `G` 的划分，每块大小都是 `|H|`。定理对有限群成立，对无限群要换成基数版本。

两条推论：元素的阶整除群的阶；对任意 `a ∈ G`，`a^{|G|} = e`。

逆命题不成立。`A_4` 的阶为 `12`，却没有阶 `6` 的子群，证明放在第 4 节。

### 1.5 费马小定理与欧拉定理

取 `G = (Z/nZ)^×`，阶为 `φ(n)`。Lagrange 定理给出欧拉定理：若 `gcd(a, n) = 1`，则

```text
a^{φ(n)} ≡ 1 (mod n)
```

`n = p` 为素数时，`φ(p) = p - 1`，得到费马小定理：`p ∤ a` 时 `a^{p-1} ≡ 1 (mod p)`。

这两个定理是群论最早的应用之一。证明不需要数论技巧，只需要「单位群是有限群」这一事实。

## 2. 正规子群与商群

### 2.1 正规子群

子群 `N ≤ G` 称为正规子群，若对任意 `g ∈ G` 有 `gNg^{-1} = N`，记作 `N ⊴ G`。

等价的说法有三条：`gN = Ng` 对一切 `g` 成立；`gNg^{-1} ⊆ N` 对一切 `g` 成立；`N` 是某个同态的核。

常见例子：`{e}` 与 `G`；中心 `Z(G)`；换位子群 `[G, G]`；任何同态的核；指数为 `2` 的子群。

指数为 `2` 的子群一定正规。因为 `G = H ∪ gH = H ∪ Hg`，补集只有一个陪集，左右陪集必然相同。

反例：`S_3` 中 `H = {e, (1 2)}` 不是正规子群。取 `g = (1 3)`，则 `gHg^{-1} = {e, (2 3)}`，与 `H` 不同。

### 2.2 商群的构造

若 `N ⊴ G`，在陪集集合 `G/N` 上定义乘法

```text
(gN)(hN) = ghN
```

良定义需要验证：若 `gN = g'N`，`hN = h'N`，则 `g' = gn_1`，`h' = hn_2`，于是

```text
g'h' = g n_1 h n_2 = gh (h^{-1} n_1 h) n_2 ∈ ghN
```

这里用到 `h^{-1} n_1 h ∈ N`，正是正规性。若 `N` 不正规，乘法依赖代表元的选取，商集不是群。

`G/N` 的单位元是 `N`，`gN` 的逆元是 `g^{-1}N`。商群的阶为 `[G:N]`。

### 2.3 同态基本定理

群同态 `φ: G → H` 保持乘法。核 `ker φ = {g : φ(g) = e}` 是 `G` 的正规子群，像 `im φ` 是 `H` 的子群。

第一同构定理：

```text
G / ker φ ≅ im φ
```

证明分三步。定义 `Φ: g·ker φ ↦ φ(g)`；良定义来自 `g^{-1}g' ∈ ker φ ⇒ φ(g) = φ(g')`；同态来自 `φ` 保持乘法；双射来自核平凡与像的定义。

这条定理把「同态的像」化为「商群」。很多结构定理的第一步都是找一个合适的同态，然后计算核。

典型例子：`Z → Z/nZ` 的核是 `nZ`；`sgn: S_n → {±1}` 的核是 `A_n`；`det: GL_n(F) → F^×` 的核是 `SL_n(F)`。

### 2.4 对应定理与同构定理

对应定理：设 `N ⊴ G`。`G` 中包含 `N` 的子群与 `G/N` 的子群一一对应，映射为 `H ↦ H/N`。正规子群对应正规子群。

第二同构定理：设 `H ≤ G`，`N ⊴ G`，则 `HN` 是子群，`N ⊴ HN`，`H ∩ N ⊴ H`，且

```text
HN / N ≅ H / (H ∩ N)
```

第三同构定理：设 `N ⊴ G`，`K ⊴ G`，`N ⊆ K`，则 `K/N ⊴ G/N`，且

```text
(G/N) / (K/N) ≅ G/K
```

三条同构定理配合使用，可以把复杂的商结构逐层拆开。

### 2.5 单群

没有非平凡正规子群的群称为单群。单群是群论中的「原子」，合成列把一般有限群分解为单群的扩张。

Abel 群单当且仅当它是素数阶循环群。因为 Abel 群的每个子群都正规，单性要求没有非平凡子群，于是群必为素数阶循环群。

非交换单群的第一个例子是 `A_5`，阶为 `60`。更一般地，`A_n` 在 `n ≥ 5` 时是单群，这条定理是五次方程没有根式解的群论基础。

`A_4` 不是单群。它的 Klein 四元子群 `V_4 = {e, (1 2)(3 4), (1 3)(2 4), (1 4)(2 3)}` 是正规子群。

## 3. 群作用

### 3.1 定义与例子

群 `G` 在集合 `X` 上的作用是映射 `G × X → X`，记 `(g, x) ↦ g·x`，满足 `e·x = x` 与 `(gh)·x = g·(h·x)`。

等价的说法是同态 `φ: G → Sym(X)`，其中 `φ(g)(x) = g·x`。核 `ker φ` 是作用的核，作用忠实当且仅当核平凡。

例子：`D_n` 作用在正 `n` 边形的顶点上；`S_n` 作用在 `{1, …, n}` 上；`G` 通过左乘作用在自身上；`G` 通过共轭作用在自身上；`GL_n(F)` 作用在 `F^n` 上。

### 3.2 轨道与稳定子

`x` 的轨道是 `Orb(x) = {g·x : g ∈ G}`，稳定子是 `Stab(x) = {g : g·x = x}`。稳定子是子群。

轨道构成 `X` 的划分：两个轨道要么相等，要么不交。只有一个轨道的作用称为传递作用。

轨道-稳定子定理：

```text
|G| = |Orb(x)| · |Stab(x)|
```

证明用双射 `G/Stab(x) → Orb(x)`，`g·Stab(x) ↦ g·x`。良定义与单射来自稳定子的定义，满射来自轨道的定义。

这个定理把「数轨道」化为「算稳定子」。传递作用满足 `|X| = [G : Stab(x)]`。

### 3.3 Burnside 引理

设 `X` 是有限 `G`-集，`X/G` 是轨道集合，则

```text
|X/G| = (1/|G|) · Σ_{g∈G} |Fix(g)|
```

其中 `Fix(g) = {x : g·x = x}`。

证明用双重计数。数满足 `g·x = x` 的对 `(g, x)`：按 `g` 求和得到左边；按 `x` 求和得到 `Σ_x |Stab(x)|`。同一轨道内 `|Stab(x)|` 相同，且等于 `|G|/|Orb(x)|`，于是每条轨道贡献 `|G|`，总和为 `|G|·|X/G|`。

一个典型应用是数项链。`n` 颗珠子、`q` 种颜色，在循环群旋转下等价，轨道数为

```text
(1/n) · Σ_{d|n} φ(d) q^{n/d}
```

### 3.4 共轭作用与类方程

`G` 通过 `g·x = gxg^{-1}` 作用在自身上。轨道是共轭类，稳定子是中心化子 `C_G(x)`。

轨道-稳定子定理给出 `|G| = |cl(x)| · |C_G(x)|`。中心 `Z(G)` 由单点共轭类组成。

把共轭类按大小分类，得到类方程

```text
|G| = |Z(G)| + Σ_i [G : C_G(x_i)]
```

其中 `x_i` 取遍非中心共轭类的代表元。

若 `|G| = p^k`，每个 `[G : C_G(x_i)]` 都是 `p` 的正幂，所以 `p` 整除 `|Z(G)|`。中心非平凡，这是 `p`-群理论的起点。

### 3.5 凯莱定理

让 `G` 通过左乘作用在自身上：`g·x = gx`。这个作用是忠实的，因为 `gx = x` 推出 `g = e`。

作用给出单同态 `G → Sym(G)`，于是 `G` 同构于 `S_G` 的一个子群。这就是凯莱定理。

有限群的情形给出 `G` 嵌入 `S_n`，其中 `n = |G|`。这个嵌入通常不是最优的，但足以说明「每个有限群都是置换群」。

## 4. Sylow 定理

### 4.1 p-群

阶为 `p^k` 的群称为 `p`-群。由类方程，非平凡 `p`-群的中心非平凡。

若 `|G| = p^2`，则 `G` 是 Abel 群。取中心中的非单位元 `z`。若 `⟨z⟩ = G`，则 `G` 循环；否则商群 `G/⟨z⟩` 阶为 `p`，取 `g` 使 `g⟨z⟩` 生成商群。`z` 在中心，与 `g` 交换，于是 `G` 由两个互相交换的元素生成，故交换。

`p`-群的中心列最终到达整个群，所以 `p`-群幂零。这条结论在第 5 节会用到。

### 4.2 三个定理

设 `|G| = p^a m`，其中 `p` 为素数且 `p ∤ m`。阶为 `p^a` 的子群称为 Sylow `p`-子群。

Sylow 第一定理：Sylow `p`-子群存在。

存在性的标准证明让 `G` 作用在大小为 `p^a` 的子集族上，利用轨道长度与二项式系数的 `p`-进性质逼出一个 Sylow 子群，细节见 Dummit–Foote 第 4 章。

Sylow 第二定理：任意两个 Sylow `p`-子群共轭。

证明思路是让一个 Sylow 子群 `Q` 左乘作用在 `G/P` 上。轨道长度的幂次与不动点计数推出不动点存在，不动点对应 `gP` 使 `Q ⊆ gPg^{-1}`，比较阶即得共轭。

Sylow 第三定理：Sylow `p`-子群的个数 `n_p` 满足

```text
n_p ≡ 1 (mod p),  n_p | m
```

证明思路是让 `P` 共轭作用在 Sylow 子群集合上。轨道长度是 `p` 的幂，不动点只有 `P` 自己，所以总数模 `p` 余 `1`；`n_p = [G : N_G(P)]` 整除 `m`。

### 4.3 小阶群的应用

阶为 `15` 的群必为循环群。`n_3 | 5` 且 `n_3 ≡ 1 (mod 3)`，只能取 `n_3 = 1`；同理 `n_5 = 1`。两个 Sylow 子群都正规，交为平凡子群，所以 `G ≅ Z/3Z × Z/5Z ≅ Z/15Z`。

阶为 `pq` 的群，其中 `p < q` 为素数。`n_q | p` 且 `n_q ≡ 1 (mod q)`，只能取 `n_q = 1`。`n_p | q` 且 `n_p ≡ 1 (mod p)`，可能取 `1` 或 `q`。若 `q ≢ 1 (mod p)`，则 `n_p = 1`，两个 Sylow 子群都正规，群为循环群。

`A_4` 没有阶 `6` 的子群。若存在这样的 `H`，其指数为 `2`，因而正规。指数为 `2` 的正规子群包含所有平方元，而 `A_4` 中的 `3`-轮换都是平方元，共 `8` 个，超过 `|H| = 6`，矛盾。

## 5. 可解群与幂零群

### 5.1 换位子

换位子定义为 `[g, h] = ghg^{-1}h^{-1}`，它等于单位元当且仅当 `g` 与 `h` 交换。

所有换位子生成的子群记作 `G' = [G, G]`，称为换位子群。它是正规子群，且 `G/G'` 是 Abel 群。

`G/G'` 是 `G` 最大的 Abel 商群：任何同态 `φ: G → A` 到 Abel 群都经过 `G'`，即存在唯一的同态 `G/G' → A` 使 `φ` 分解。

### 5.2 导列与可解群

令 `G^{(0)} = G`，`G^{(i+1)} = [G^{(i)}, G^{(i)}]`，得到导列

```text
G = G^{(0)} ⊇ G^{(1)} ⊇ G^{(2)} ⊇ …
```

每一项都是前一族的正规子群。若某一项等于平凡子群，称 `G` 可解。

Abel 群可解，因为 `G' = {e}`。`S_3` 可解：`S_3' = A_3`，`A_3' = {e}`。`S_4` 可解：`S_4' = A_4`，`A_4' = V_4`，`V_4' = {e}`。

`S_n` 在 `n ≤ 4` 时可解，在 `n ≥ 5` 时不可解。因为 `A_5` 是非交换单群，而可解性会传递到子群，`A_n` 在 `n ≥ 5` 时不可解，进而 `S_n` 不可解。

可解性是伽罗瓦理论的判别条件：方程有根式解，当且仅当它的伽罗瓦群可解。

### 5.3 合成列

有限群的合成列是子群链

```text
{e} = G_0 ⊴ G_1 ⊴ … ⊴ G_r = G
```

其中每个商 `G_{i+1}/G_i` 是单群。这些商称为合成因子。

Jordan–Hölder 定理：任意两条合成列的合成因子相同，只差顺序与同构。

有限群可解，当且仅当它的合成因子都是素数阶循环群。这条等价把「可解」从导列翻译成「单群原子都是交换的」。

### 5.4 幂零群

幂零群的条件比可解强。令 `Z_0 = {e}`，`Z_{i+1}/Z_i = Z(G/Z_i)`，得到上中心列

```text
{e} = Z_0 ⊆ Z_1 ⊆ Z_2 ⊆ …
```

若某一项等于 `G`，称 `G` 幂零。

等价地，令 `γ_1 = G`，`γ_{i+1} = [γ_i, G]`，得到下中心列；`G` 幂零当且仅当某一项等于平凡子群。

有限幂零群同构于其 Sylow 子群的直积，也等价于所有 Sylow 子群都正规。`p`-群是幂零群。

幂零群一定可解，反之不成立。`S_3` 可解，中心平凡，不是幂零群。

## 6. 自由群与表现

### 6.1 自由群的构造

设 `S` 是集合，字母表取 `S ∪ S^{-1}`，其中 `S^{-1}` 是形式逆元。由字母组成的有限串称为字。

若字中出现相邻的 `ss^{-1}` 或 `s^{-1}s`，删除它们。反复删除直到不能删，得到约化字。空串记作 `e`。

约化字在「连接后约化」的运算下构成群 `F(S)`，称为 `S` 上的自由群。结合律需要验证约化过程与括号无关，标准做法是把字看成树或使用重写系统。

每个元素有唯一的约化字表示，这是自由群的正常形式。逆元是把字倒序并把每个字母换成逆字母。

### 6.2 泛性质

自由群由一条泛性质刻画：任意映射 `f: S → G` 都唯一延拓为同态 `φ: F(S) → G`。

存在性：把生成元映到 `f(s)`，再把字逐字母相乘。唯一性：`F(S)` 由 `S` 生成，同态在生成元上的取值决定一切。

这条性质说明自由群是「只受生成元约束」的群。它也是范畴论中自由对象的原型：自由函子是遗忘函子的左伴随。

### 6.3 群表现

在自由群上再加关系，得到群的表现：

```text
⟨S | R⟩ = F(S) / ⟨⟨R⟩⟩
```

其中 `R` 是一组字，`⟨⟨R⟩⟩` 是 `R` 生成的正规子群。元素是生成元的字，关系是允许令其等于单位元的等式。

例子：

```text
D_n = ⟨r, s | r^n = 1, s^2 = 1, srs = r^{-1}⟩
Z/nZ = ⟨x | x^n = 1⟩
Z^2 = ⟨a, b | aba^{-1}b^{-1} = 1⟩
```

表现把「构造群」变成「写生成元与关系」。代价是同一个群可以有无穷多种表现，而且判定两个有限表现是否给出同构的群一般不可判定，这是 Novikov 与 Boone 的结果。

### 6.4 Abel 化

对任意群 `G`，`G^{ab} = G/[G, G]` 称为 Abel 化。它是 `G` 最大的 Abel 商群。

自由群的 Abel 化是自由 Abel 群：

```text
F(S)^{ab} ≅ ⊕_{s∈S} Z
```

生成元数等于 `S` 的基数。这一步把自由群与线性代数接起来，也是同调代数的起点。

## 7. 范畴视角

### 7.1 群作为范畴

把群 `G` 看成只有一个对象的范畴 `BG`：对象记作 `*`，态射是 `G` 的元素，复合是乘法，单位态射是 `e`。

群同态 `φ: G → H` 就是函子 `BG → BH`：对象映到对象，态射映到态射，保持复合与单位。

这个翻译把「群」变成了「单对象范畴」，很多群论构造因此可以放进范畴语言。

### 7.2 作用与函子

`G` 在集合 `X` 上的作用就是一个函子 `BG → Set`。对象 `*` 映到 `X`，态射 `g` 映到置换 `x ↦ g·x`。

函子保持复合与单位，对应的正是作用的结合律与单位元条件。作用之间的自然变换就是 `G`-等变映射。

在这个语言下，轨道分解是集合的余积分解，传递作用对应单对象的余积项。

### 7.3 商与核的泛性质

在群范畴 `Grp` 中，商群 `G/N` 是包含映射 `N → G` 与常值映射 `N → G` 的余等化子。它把所有 `N` 中的元素粘到单位元。

同态的核 `ker φ` 是 `φ` 与平凡同态的等化子。它把「被 `φ` 映到单位元」的元素挑出来。

积与余积分别对应直积与自由积。这些构造在第 5 章会用统一的极限语言重述。

### 7.4 凯莱定理与米田引理

把 `*` 的 Hom 函子作用在自身上：`Hom(*, -)` 把 `*` 送到 `G`，给出 `G` 在自身上的正则作用。

米田引理说，从 `Hom(*, -)` 到自身的自然变换与 `G` 的元素一一对应。凯莱定理因此可以看成米田引理在单对象范畴上的特例。

## 8. 书目与读法

### 8.1 主读

主读是 Dummit 与 Foote 的《Abstract Algebra》第 3 版第 1 至 6 章：

| 章 | 主题 | 关键结果 |
| --- | --- | --- |
| 1 | 群导引 | 群的定义、二面体群、对称群 |
| 2 | 子群 | 子群判别、循环群、生成元 |
| 3 | 商群与同态 | 正规子群、商群、同构定理 |
| 4 | 群作用 | 轨道、稳定子、Burnside 引理 |
| 5 | 直积与半直积 | 有限生成 Abel 群的基本定理 |
| 6 | 群论的进一步主题 | Sylow 定理、可解群、幂零群、自由群 |

### 8.2 并读

并行读物是 Fraleigh 与 Brand 的《A First Course in Abstract Algebra》第 8 版，前四部分为群与子群、群的结构、同态与商群、高级群论。

该书例子多、习题偏计算，适合第一遍。第 V 至 IX 部分依次为环与域、构造环与域、交换代数、扩域、伽罗瓦理论，正好接上后续几章。

### 8.3 读法

第 1 至 3 章连续读，商群依赖正规子群。第 4 章可以与第 6 章的 Sylow 部分合并。第 5 章的直积与半直积可以后置，等有限群的例子见得多一些再读。

若目标是伽罗瓦理论，第 4 章与第 6 章的可解群必须掌握，Sylow 定理至少要会用于小阶群的存在性与唯一性判定。自由群与表现可以略读，等读到同调代数再回来。
