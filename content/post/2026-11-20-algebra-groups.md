群论研究对称性。对称性可以来自图形、置换或同余，抽象出来都是同一个结构：集合配上满足结合律、有单位元、有逆元的运算。

本章按教材体例组织：例子先行，随后给出定义、命题、引理、定理与推论，证明紧随陈述。编号按节进行，例如定理 3.3 是第 3 节的第 3 条。

## 0. 例子与定义

群论的入口是三类具体对象：正多边形的对称、置换、模 `n` 的剩余类。先看例子，再抽公理。

> **例 0.1（二面体群）**
>
> 正 `n` 边形的对称构成二面体群 `D_n`。旋转 `r` 每次转 `2π/n`，反射 `s` 关于一条对称轴翻转。生成元满足 `r^n = 1`，`s^2 = 1`，`srs^{-1} = r^{-1}`，共 `2n` 个元素。`D_3 ≅ S_3`；`D_4` 是正方形的对称群，阶为 `8`，与四元数群 `Q_8` 不同构。

> **例 0.2（对称群）**
>
> `n` 个文字的置换构成对称群 `S_n`，阶为 `n!`。每个置换分解为不相交轮换的乘积，轮换长度的最小公倍数就是它的阶。符号同态 `sgn: S_n → {±1}` 的核是交错群 `A_n`，阶为 `n!/2`。

> **例 0.3（剩余类群）**
>
> `Z/nZ` 在加法下是 `n` 阶循环群。与 `n` 互素的剩余类在乘法下构成单位群 `(Z/nZ)^×`，阶为 `φ(n)`。例如 `(Z/6Z)^× = {1, 5} ≅ Z/2Z`。

> **定义 0.4（群）**
>
> 群是集合 `G` 与二元运算 `·`，满足结合律、存在单位元 `e`、每个元素有逆元。若运算还满足交换律，称为 Abel 群。

> **命题 0.5（基本性质）**
>
> 设 `G` 为群，`a, b, c ∈ G`。则
>
> - 单位元唯一。
> - 每个元素的逆元唯一。
> - 消去律成立：`ab = ac` 蕴含 `b = c`，`ba = ca` 蕴含 `b = c`。
> - `(ab)^{-1} = b^{-1}a^{-1}`，`(a^{-1})^{-1} = a`。

证明　设 `e, e'` 都是单位元，则 `e = ee' = e'`。设 `b, c` 都是 `a` 的逆元，则 `b = be = b(ac) = (ba)c = ec = c`。消去律由左乘 `a^{-1}` 或右乘 `a^{-1}` 得到。最后

```text
(ab)(b^{-1}a^{-1}) = a(bb^{-1})a^{-1} = aa^{-1} = e
```

另一侧同理，故 `(ab)^{-1} = b^{-1}a^{-1}`。

> **定义 0.6（群的阶）**
>
> 群 `G` 的元素个数称为群的阶，记作 `|G|`。

## 1. 子群与生成

> **定义 1.1（子群）**
>
> 群 `G` 的非空子集 `H` 若在继承的运算下仍是群，称为子群，记作 `H ≤ G`。`{e}` 与 `G` 称为平凡子群，其余子群称为非平凡子群。若 `H ≠ G`，称为真子群。

> **引理 1.2（子群判别）**
>
> 非空子集 `H ⊂ G` 是子群，当且仅当对任意 `a, b ∈ H` 有 `ab^{-1} ∈ H`。

证明　必要性显然。反之取 `a ∈ H`，由 `aa^{-1} = e ∈ H` 得单位元；由 `eb^{-1} = b^{-1} ∈ H` 得逆元；由 `a(b^{-1})^{-1} = ab ∈ H` 得乘法封闭。

> **命题 1.3（子群的交）**
>
> 一族子群的交仍是子群。

证明　设 `{H_i}` 是一族子群，其交至少含 `e`。任取 `a, b ∈ ∩ H_i`，对每个 `i` 有 `ab^{-1} ∈ H_i`，故 `ab^{-1} ∈ ∩ H_i`，由引理 1.2 得证。

> **定义 1.4（生成子群）**
>
> 设 `S ⊂ G`。所有包含 `S` 的子群的交称为 `S` 生成的子群，记作 `⟨S⟩`。它的元素是 `S` 中元素及其逆元的有限乘积。

## 2. 循环群

> **定义 2.1（循环群与元素的阶）**
>
> 设 `g ∈ G`。若存在正整数 `n` 使 `g^n = e`，最小的这样的 `n` 称为 `g` 的阶；若不存在，称 `g` 的阶无限。若 `G = ⟨g⟩`，称 `G` 为循环群，`g` 为生成元。

> **命题 2.2（生成元的阶）**
>
> 设 `G = ⟨g⟩`。若 `g` 的阶为 `n`，则 `|G| = n`；若 `g` 的阶无限，则 `G` 是无限群。

证明　设 `g` 的阶为 `n`。若 `0 ≤ i < j < n` 且 `g^i = g^j`，则 `g^{j-i} = e`，与 `n` 的最小性矛盾。故 `e, g, …, g^{n-1}` 两两不同。

对任意整数 `k`，带余除法给出 `k = qn + r`，`0 ≤ r < n`，于是 `g^k = g^r`。故 `G = {e, g, …, g^{n-1}}`，`|G| = n`。

若 `g` 的阶无限，则 `g^i ≠ g^j` 对一切 `i ≠ j` 成立，故 `G` 含无限多个元素。

> **定理 2.3（循环群的分类）**
>
> 无限循环群同构于 `Z`；`n` 阶循环群同构于 `Z/nZ`。

证明　若 `g` 的阶无限，由命题 2.2，`G` 与 `Z` 的元素一一对应；映射 `k ↦ g^k` 保持加法，故 `Z ≅ G`。

若 `g` 的阶为 `n`，由命题 2.2，`G = {e, g, …, g^{n-1}}`。映射 `k mod n ↦ g^k` 是双射，且保持加法，故 `Z/nZ ≅ G`。

> **命题 2.4（循环群的子群）**
>
> 循环群的子群仍是循环群。`Z` 的子群为 `dZ`；`Z/nZ` 的子群与 `n` 的正因子一一对应。

证明　设 `H ≤ Z` 非零，取 `d` 为 `H` 中的最小正整数。对任意 `h ∈ H`，带余除法给出 `h = qd + r`，`0 ≤ r < d`。由 `r ∈ H` 与 `d` 的最小性得 `r = 0`，故 `H = dZ`。

商群情形取商映射 `Z → Z/nZ` 的原像，得到 `dZ/nZ`，其中 `d | n`。

## 3. 陪集与 Lagrange 定理

> **定义 3.1（左平移、左陪集与指数）**
>
> 设 `g ∈ G`。映射 `L_g: G → G`，`x ↦ gx` 称为由 `g` 给出的左平移，它是以 `L_{g^{-1}}` 为逆的双射。
>
> 设 `H ≤ G`。`H` 在 `L_g` 下的像 `gH = {gh : h ∈ H}` 就是把 `H` 左平移 `g` 的结果，称为由 `g` 确定的 `H` 的左陪集。左陪集的个数称为 `H` 在 `G` 中的指数，记作 `[G:H]`。

> **引理 3.2（陪集的性质）**
>
> 设 `H ≤ G`。则
>
> - `gH = g'H` 当且仅当 `g^{-1}g' ∈ H`。
> - 任意两个左陪集相等或不相交。
> - 左平移 `L_g` 限制在 `H` 上，给出 `H` 与 `gH` 的双射。

证明　第一条：`gH = g'H` 等价于 `g^{-1}g'H = H`，即 `g^{-1}g' ∈ H`。第二条：若 `x ∈ gH ∩ g'H`，则 `gH = xH = g'H`。第三条：`L_g` 是双射，故 `h ↦ gh` 是 `H` 到 `gH` 的双射。

> **定理 3.3（Lagrange 定理）**
>
> 设 `G` 为有限群，`H ≤ G`，则 `|G| = |H| · [G:H]`。

证明　左陪集构成 `G` 的划分，每个陪集与 `H` 等势，故 `|G|` 等于陪集个数乘以 `|H|`。

> **推论 3.4（阶与幂）**
>
> 有限群中，元素的阶整除群的阶；对任意 `a ∈ G`，`a^{|G|} = e`。

证明　`⟨a⟩` 的阶就是 `a` 的阶，由 Lagrange 定理整除 `|G|`。设 `|G| = k·ord(a)`，则 `a^{|G|} = (a^{ord(a)})^k = e`。

> **推论 3.5（Euler 定理与 Fermat 小定理）**
>
> 若 `gcd(a, n) = 1`，则 `a^{φ(n)} ≡ 1 (mod n)`。若 `p` 为素数且 `p ∤ a`，则 `a^{p-1} ≡ 1 (mod p)`。

证明　对单位群 `(Z/nZ)^×` 用推论 3.4，其阶为 `φ(n)`。取 `n = p`，得 `a^{p-1} ≡ 1 (mod p)`。

## 4. 正规子群与商群

> **定义 4.1（共轭）**
>
> 设 `g ∈ G`。映射 `c_g: G → G`，`x ↦ gxg^{-1}` 称为由 `g` 给出的共轭。`c_g(x)` 与 `x` 互为共轭，`x` 的全部共轭构成 `x` 的共轭类。`c_g` 保持乘法，且以 `c_{g^{-1}}` 为逆，故是 `G` 的自同构，称为内自同构。

> **定义 4.2（正规子群）**
>
> 子群 `N ≤ G` 称为正规子群，若它在任意共轭下不变：对一切 `g ∈ G` 有 `c_g(N) = N`，即 `gNg^{-1} = N`，记作 `N ⊴ G`。

> **引理 4.3（正规性的等价条件）**
>
> 对 `N ≤ G`，下列条件等价：
>
> - `c_g(N) = N` 对一切 `g` 成立。
> - `gN = Ng` 对一切 `g` 成立。
> - `gNg^{-1} ⊆ N` 对一切 `g` 成立。
> - `N` 是某个同态的核。
> - `N` 是若干共轭类的并。

证明　第一条与第二条都等价于左右陪集相同。第一条显然推出第三条；对 `g^{-1}` 用第三条得 `g^{-1}Ng ⊆ N`，即 `N ⊆ gNg^{-1}`，故第三条也推出第一条。

若 `N = ker f`，则 `f(gng^{-1}) = f(g)e f(g)^{-1} = e`，故 `gNg^{-1} ⊆ N`。反之 `N` 正规时，它是商映射 `G → G/N` 的核。

最后，`N` 在共轭下不变，等价于对每个 `n ∈ N`，`n` 的整个共轭类都含于 `N`。因此 `N` 是若干共轭类的并；反之，共轭类的并显然在共轭下不变。

> **例 4.4（正规与非正规）**
>
> `{e}` 与 `G` 都是正规子群；任何同态的核正规；指数为 `2` 的子群正规。`S_3` 中 `H = {e, (1 2)}` 不是正规子群：在 `(1 3)` 的共轭下，它变成 `{e, (2 3)}`。

> **引理 4.5（指数 2 的子群）**
>
> 指数为 `2` 的子群一定正规。

证明　取 `g ∉ H`，则 `G = H ∪ gH = H ∪ Hg`。补集只有一个陪集，故 `gH = Hg`。

> **定理 4.6（商群）**
>
> 设 `N ⊴ G`。陪集集合 `G/N` 在运算 `(gN)(hN) = ghN` 下构成群，阶为 `[G:N]`。

证明　良定义：若 `gN = g'N`，`hN = h'N`，则 `g' = gn_1`，`h' = hn_2`，于是

```text
g'h' = gh (h^{-1}n_1h) n_2 ∈ ghN
```

这里用到 `h^{-1}n_1h ∈ N`，正是正规性。结合律继承自 `G`，单位元为 `N`，`gN` 的逆元为 `g^{-1}N`。

## 5. 同态与同构定理

> **定义 5.1（同态、核与像）**
>
> 映射 `f: G → H` 若满足 `f(ab) = f(a)f(b)`，称为群同态。核 `ker f = {g : f(g) = e}`，像 `im f = f(G)`。

> **引理 5.2（核是正规子群）**
>
> 设 `f: G → H` 为群同态。则 `ker f` 是 `G` 的正规子群，`im f` 是 `H` 的子群。

证明　`f(e) = e`，`f(g^{-1}) = f(g)^{-1}`，故核非空且对乘法与逆元封闭。对 `n ∈ ker f`，

```text
f(gng^{-1}) = f(g)f(n)f(g)^{-1} = f(g)e f(g)^{-1} = e
```

故 `gng^{-1} ∈ ker f`，核正规。像对乘法与逆元封闭，故为子群。

> **定理 5.3（第一同构定理）**
>
> 设 `f: G → H` 为群同态。则 `G / ker f ≅ im f`。

证明　定义

```text
F: G/ker f → im f,  F(g·ker f) = f(g)
```

先说明 `F` 与代表元的选取无关。设 `g·ker f = g'·ker f`，则 `g^{-1}g' ∈ ker f`，即 `f(g^{-1}g') = e`。于是

```text
f(g)^{-1} f(g') = f(g^{-1}) f(g') = f(g^{-1}g') = e
```

故 `f(g) = f(g')`。同一个陪集中的元素在 `F` 下有相同的像，`F` 不依赖代表元。

`F` 保持乘法。若 `F(g·ker f) = e`，则 `f(g) = e`，即 `g ∈ ker f`，故 `g·ker f = ker f`，核平凡，`F` 为单射。`F` 的像就是 `im f`，故为满射。

> **定理 5.4（商群的泛性质）**
>
> 设 `N ⊴ G`，`π: G → G/N` 为商映射。对任意同态 `f: G → H`，若 `N ⊆ ker f`，则存在唯一同态 `G/N → H` 使它与 `π` 的复合等于 `f`。

证明　存在性：定义 `G/N → H`，`gN ↦ f(g)`。若 `gN = g'N`，则 `g^{-1}g' ∈ N ⊆ ker f`，故 `f(g) = f(g')`，映射良定义。它保持乘法。

唯一性：`π` 满射，任何满足条件的同态在 `gN = π(g)` 上必须取 `f(g)`。

取 `N = ker f`，泛性质给出 `G/ker f → H` 的同态；它的像为 `im f`，核只有单位陪集，故收缩值域后就是定理 5.3 的同构。第一同构定理因此可以看成泛性质的推论。

> **定理 5.5（对应定理）**
>
> 设 `N ⊴ G`。`G` 中包含 `N` 的子群与 `G/N` 的子群一一对应，映射为 `H ↦ H/N`；正规子群对应正规子群。

证明　逆映射把 `G/N` 的子群 `K` 送到它在商映射下的原像。两个方向互逆，且正规性在商群与原群之间保持一致。

> **定理 5.6（第二同构定理）**
>
> 设 `H ≤ G`，`N ⊴ G`。则 `HN ≤ G`，`N ⊴ HN`，`H ∩ N ⊴ H`，且 `HN/N ≅ H/(H ∩ N)`。

证明　先说明 `HN` 是子群。设 `h_1 n_1, h_2 n_2 ∈ HN`。由 `N` 正规，

```text
(h_1 n_1)(h_2 n_2)^{-1} = h_1 h_2^{-1} · (h_2 n_1 n_2^{-1} h_2^{-1}) ∈ HN
```

故 `HN ≤ G`。`N` 在 `G` 中正规，在 `HN` 中也正规；`H ∩ N` 在 `H` 中共轭不变，故 `H ∩ N ⊴ H`。

定义 `q: H → HN/N`，`q(h) = hN`。它是同态，核为 `{h : hN = N} = H ∩ N`。

像为 `HN/N`：任意 `hnN` 满足 `hnN = hN = q(h)`。由第一同构定理，`H/(H ∩ N) ≅ HN/N`。

> **定理 5.7（第三同构定理）**
>
> 设 `N ⊴ G`，`K ⊴ G`，`N ⊆ K`。则 `K/N ⊴ G/N`，且 `(G/N)/(K/N) ≅ G/K`。

证明　定义 `ψ: G/N → G/K`，`ψ(gN) = gK`。

良定义：若 `gN = g'N`，则 `g^{-1}g' ∈ N ⊆ K`，故 `gK = g'K`。`ψ` 保持乘法。

核为 `{gN : gK = K} = {gN : g ∈ K} = K/N`。像为 `G/K`：任意 `gK` 都是 `gN` 的像。

由第一同构定理，`(G/N)/(K/N) ≅ G/K`。`K/N` 在 `G/N` 中正规，因为它是同态 `ψ` 的核。

> **定义 5.8（单群）**
>
> 没有非平凡正规子群的群称为单群。

> **命题 5.9（Abel 单群）**
>
> Abel 群单，当且仅当它是素数阶循环群。

证明　Abel 群的每个子群都正规，单性要求没有非平凡子群，故群必为素数阶循环群。反之，素数阶群没有非平凡子群。

> **定理 5.10（交错群的单性）**
>
> `A_n` 在 `n ≥ 5` 时是单群。

证明略述　`A_n` 由 `3`-轮换生成。设 `N ⊴ A_n` 非平凡，取 `σ ∈ N` 非单位元。用 `3`-轮换共轭可将 `σ` 化为含 `3`-轮换的形态，说明 `N` 含一个 `3`-轮换；再由共轭得到全部 `3`-轮换，故 `N = A_n`。完整分类见 Dummit–Foote 第 4.6 节。

## 6. 群作用

> **定义 6.1（群作用）**
>
> 群 `G` 在集合 `X` 上的作用是映射 `G × X → X`，`(g, x) ↦ g·x`，满足 `e·x = x` 与 `(gh)·x = g·(h·x)`。

> **引理 6.2（作用与同态）**
>
> `G` 在 `X` 上的作用等价于同态 `G → Sym(X)`。

证明　给定作用，令 `f(g)(x) = g·x`。作用公理保证 `f(g)` 是双射，且 `f(gh) = f(g)f(h)`。反之给定同态，令 `g·x = f(g)(x)`，两条公理成立。

> **例 6.3（作用的例子）**
>
> `D_n` 作用在正 `n` 边形的顶点上；`S_n` 作用在 `{1, …, n}` 上；`G` 通过左乘作用在自身上；`G` 通过共轭作用在自身上；`GL_n(F)` 作用在 `F^n` 上。

> **定义 6.4（轨道与稳定子）**
>
> `x` 的轨道是 `Orb(x) = {g·x : g ∈ G}`，稳定子是 `Stab(x) = {g : g·x = x}`。

> **引理 6.5（轨道划分）**
>
> 轨道构成 `X` 的划分，稳定子是子群。

证明　`x = e·x ∈ Orb(x)`。若 `Orb(x) ∩ Orb(y)` 非空，取 `z = g·x = h·y`，则 `x = g^{-1}h·y`，故 `Orb(x) = Orb(y)`。稳定子对乘法与逆元封闭。

> **定理 6.6（轨道-稳定子定理）**
>
> `|G| = |Orb(x)| · |Stab(x)|`。

证明　映射 `G/Stab(x) → Orb(x)`，`g·Stab(x) ↦ g·x`。若 `g·x = g'·x`，则 `g^{-1}g' ∈ Stab(x)`，故良定义且为单射；满射由轨道的定义得到。于是 `[G:Stab(x)] = |Orb(x)|`，再用 Lagrange 定理。

> **推论 6.7（传递作用）**
>
> 若作用传递，则 `|X| = [G : Stab(x)]`。

> **定理 6.8（Burnside 引理）**
>
> `|X/G| = (1/|G|) · Σ_{g∈G} |Fix(g)|`，其中 `Fix(g) = {x : g·x = x}`。

证明　双重计数满足 `g·x = x` 的对 `(g, x)`。按 `g` 求和得 `Σ_g |Fix(g)|`；按 `x` 求和得 `Σ_x |Stab(x)|`。

同一轨道内 `|Stab(x)| = |G|/|Orb(x)|`，每条轨道贡献 `|G|`，总和为 `|G|·|X/G|`。两边除以 `|G|` 即得。

> **例 6.9（项链计数）**
>
> `n` 颗珠子、`q` 种颜色，在循环群旋转下等价，轨道数为 `(1/n) · Σ_{d|n} φ(d) q^{n/d}`。

> **定理 6.10（Cayley 定理）**
>
> 每个群同构于某个置换群的子群。

证明　左乘作用 `g·x = gx` 是忠实的：`gx = x` 推出 `g = e`。故 `G → Sym(G)` 是单同态。

## 7. 共轭作用与类方程

> **命题 7.1（共轭类与中心化子）**
>
> `G` 通过定义 4.1 的共轭 `g·x = gxg^{-1}` 作用在自身上。轨道是共轭类，稳定子是中心化子 `C_G(x)`，且 `|cl(x)| = [G : C_G(x)]`。

证明　直接验证作用公理。轨道由所有共轭 `gxg^{-1}` 组成；`gxg^{-1} = x` 等价于 `gx = xg`，故稳定子为 `C_G(x)`。指数公式来自轨道-稳定子定理。

> **定理 7.2（类方程）**
>
> `|G| = |Z(G)| + Σ_i [G : C_G(x_i)]`，其中 `x_i` 取遍非中心共轭类的代表元。

证明　共轭类划分 `G`。中心元素自成一类，其余共轭类按代表元求和，再用命题 7.1。

> **推论 7.3（p-群的中心）**
>
> 非平凡 `p`-群的中心非平凡。

证明　类方程中每个 `[G : C_G(x_i)]` 都是 `p` 的正幂，故 `p` 整除 `|Z(G)|`，中心至少含 `e` 以外的元素。

## 8. Sylow 定理

> **定义 8.1（p-群与 Sylow 子群）**
>
> 阶为 `p^k` 的群称为 `p`-群。设 `|G| = p^a m`，`p ∤ m`，阶为 `p^a` 的子群称为 Sylow `p`-子群。

> **引理 8.2（p^2 群交换）**
>
> 阶为 `p^2` 的群是 Abel 群。

证明　取中心中的非单位元 `z`。若 `⟨z⟩ = G`，则 `G` 循环。否则 `G/⟨z⟩` 阶为 `p`，取 `g` 使其陪集生成商群。

于是 `G = ⟨z, g⟩`。`z` 在中心，与 `g` 交换，故 `G` 由两个互相交换的元素生成，是 Abel 群。

> **定理 8.3（Sylow 第一定理）**
>
> Sylow `p`-子群存在。

证明思路　令 `G` 作用在大小为 `p^a` 的子集族上。二项式系数模 `p` 等于 `m`，故某个轨道 `O` 的长度不被 `p` 整除。

若 `O` 是单点集，则 `m = 1`，`G` 本身是 `p`-群；否则稳定子是真子群，对 `|G|` 归纳即得 Sylow 子群。

> **定理 8.4（Sylow 第二定理）**
>
> 任意两个 Sylow `p`-子群共轭。

证明思路　设 `P, Q` 是 Sylow 子群，让 `Q` 左乘作用在 `G/P` 上。不动点个数模 `p` 等于 `|G/P| = m`，故不动点存在。

不动点 `gP` 满足 `Q ⊆ gPg^{-1}`，比较阶得 `Q = gPg^{-1}`。

> **定理 8.5（Sylow 第三定理）**
>
> Sylow `p`-子群的个数 `n_p` 满足 `n_p ≡ 1 (mod p)` 且 `n_p | m`。

证明思路　让 `P` 共轭作用在 Sylow 子群集合上。轨道长度是 `p` 的幂，不动点只有 `P`，故 `n_p ≡ 1 (mod p)`。

又 `n_p = [G : N_G(P)]`，整除 `[G:P] = m`。

> **推论 8.6（Cauchy 定理）**
>
> 若素数 `p` 整除 `|G|`，则 `G` 含 `p` 阶元素。

证明　取 Sylow `p`-子群 `P`，它非平凡。取 `x ≠ e`，其阶为 `p^k`，则 `x^{p^{k-1}}` 的阶为 `p`。

> **推论 8.7（正规性判据）**
>
> `n_p = 1` 当且仅当 Sylow `p`-子群正规。

证明　唯一时共轭保持它，故正规；正规时所有共轭都等于它，故唯一。

> **例 8.8（阶 15 的群）**
>
> `n_3 | 5` 且 `n_3 ≡ 1 (mod 3)`，只能取 `n_3 = 1`；同理 `n_5 = 1`。两个 Sylow 子群都正规，交为平凡子群，故 `G ≅ Z/3Z × Z/5Z ≅ Z/15Z`。

> **例 8.9（阶 pq 的群）**
>
> 设 `p < q` 为素数。`n_q | p` 且 `n_q ≡ 1 (mod q)`，只能取 `n_q = 1`。

`n_p | q` 且 `n_p ≡ 1 (mod p)`，可能取 `1` 或 `q`。若 `q ≢ 1 (mod p)`，则 `n_p = 1`，群为循环群。

> **例 8.10（A4 无六阶子群）**
>
> `A_4` 的阶为 `12`。若存在阶 `6` 的子群 `H`，其指数为 `2`，因而正规。指数为 `2` 的正规子群包含所有平方元。

`A_4` 中的 `3`-轮换都是平方元，共 `8` 个，超过 `|H| = 6`，矛盾。

## 9. 可解群

> **定义 9.1（换位子与换位子群）**
>
> `[g, h] = ghg^{-1}h^{-1}` 称为换位子。所有换位子生成的子群记作 `G' = [G, G]`，称为换位子群。

> **引理 9.2（换位子恒等式）**
>
> 对任意 `g, h, g_1, h_1 ∈ G`，有
>
> - `[g, h]^{-1} = [h, g]`。
> - `g[g_1, h_1]g^{-1} = [gg_1g^{-1}, gh_1g^{-1}]`。
> - `[g, h] = e` 当且仅当 `g` 与 `h` 交换。

证明　三条都可由直接计算得到。第三条：`ghg^{-1}h^{-1} = e` 等价于 `gh = hg`。

> **命题 9.3（G' 的正规性与交换化）**
>
> `G' ⊴ G`，且 `G/G'` 是 Abel 群。

证明　由引理 9.2 第二条，共轭保持换位子，故 `G'` 正规。

在 `G/G'` 中，`[gG', hG'] = [g, h]G' = G'`，故任意两个元素交换。

> **定理 9.4（交换化的泛性质）**
>
> 对任意 Abel 群 `A` 与同态 `f: G → A`，存在唯一同态 `G/G' → A` 使 `f` 分解为 `G → G/G' → A`。

证明　因 `A` 交换，`f([g, h]) = e`，故 `G' ⊆ ker f`。由第一同构定理的对应，`f` 诱导出 `G/G' → A` 的同态。

> **定义 9.5（导列与可解群）**
>
> 令 `G^{(0)} = G`，`G^{(i+1)} = [G^{(i)}, G^{(i)}]`。若某个 `G^{(n)} = {e}`，称 `G` 可解。

> **命题 9.6（可解性的封闭性）**
>
> 可解群的子群与商群可解；若 `N ⊴ G` 且 `N` 与 `G/N` 都可解，则 `G` 可解。

证明略述　子群情形由 `H^{(i)} ⊆ G^{(i)}` 归纳。商群情形由 `(G/N)^{(i)} = G^{(i)}N/N` 归纳。扩张情形把 `N` 与 `G/N` 的导列接起来。

> **定理 9.7（S_n 的可解性）**
>
> `S_n` 可解当且仅当 `n ≤ 4`。

证明　`S_3` 与 `S_4` 的导列可以直接算出：

```text
S_3' = A_3,  A_3' = {e}
S_4' = A_4,  A_4' = V_4,  V_4' = {e}
```

故 `S_3` 与 `S_4` 可解。

`n ≥ 5` 时 `A_5` 是非交换单群，且 `A_5 ⊆ A_n`。可解性传递到子群，故 `A_n` 不可解，`S_n` 也不可解。

## 10. 合成列与幂零群

> **定义 10.1（合成列）**
>
> 有限群的合成列是子群链
>
> `{e} = G_0 ⊴ G_1 ⊴ … ⊴ G_r = G`
>
> 其中每个商 `G_{i+1}/G_i` 是单群。这些商称为合成因子。

> **定理 10.2（Jordan–Hölder 定理）**
>
> 任意两条合成列的合成因子相同，只差顺序与同构。

> **定理 10.3（可解的合成因子判据）**
>
> 有限群可解，当且仅当它的合成因子都是素数阶循环群。

> **定义 10.4（幂零群）**
>
> 令 `Z_0 = {e}`，`Z_{i+1}/Z_i = Z(G/Z_i)`。若某个 `Z_n = G`，称 `G` 幂零。

> **定理 10.5（有限幂零群的等价条件）**
>
> 有限群 `G` 幂零，当且仅当它的每个 Sylow 子群都正规，当且仅当 `G` 同构于其 Sylow 子群的直积。

> **命题 10.6（幂零蕴含可解）**
>
> 幂零群可解；`S_3` 可解但不是幂零群。

证明　上中心列的相邻商都是交换群，故幂零群可解。`S_3` 的中心平凡，上中心列停在 `{e}`，故不幂零。

## 11. 自由群与表现

> **定义 11.1（自由群）**
>
> 设 `S` 是集合，字母表为 `S ∪ S^{-1}`。约化字在连接与约化下构成群 `F(S)`，称为 `S` 上的自由群。

> **定理 11.2（自由群的泛性质）**
>
> 任意映射 `f: S → G` 唯一延拓为同态 `F(S) → G`。

证明　存在性：把生成元映到 `f(s)`，字逐字母相乘。唯一性：`F(S)` 由 `S` 生成，同态由生成元上的值决定。

> **推论 11.3（唯一性）**
>
> 满足同一泛性质的两个自由群在同构意义下唯一。

> **定义 11.4（群表现）**
>
> `⟨S | R⟩ = F(S)/⟨⟨R⟩⟩`，其中 `⟨⟨R⟩⟩` 是 `R` 生成的正规子群。

> **例 11.5（表现的例子）**
>
> `D_n = ⟨r, s | r^n = 1, s^2 = 1, srs = r^{-1}⟩`，`Z/nZ = ⟨x | x^n = 1⟩`，`Z^2 = ⟨a, b | aba^{-1}b^{-1} = 1⟩`。

> **命题 11.6（Abel 化）**
>
> `G^{ab} = G/[G, G]` 是 `G` 最大的 Abel 商群。

> **定理 11.7（自由群的 Abel 化）**
>
> `F(S)^{ab} ≅ ⊕_{s∈S} Z`。

证明　`F(S)` 的换位子群由 `[s, t]`（`s, t ∈ S`）正规生成。商群中所有生成元交换，且没有其他关系，故是以 `S` 为基的自由 Abel 群。

## 12. 范畴视角

> **定义 12.1（单对象范畴）**
>
> 群 `G` 可以看成一个只有一个对象的范畴 `BG`：对象为 `*`，态射为 `G` 的元素，复合为乘法，单位态射为 `e`。

> **命题 12.2（作用与函子）**
>
> `G` 在 `X` 上的作用等价于函子 `BG → Set`；作用之间的自然变换就是 `G`-等变映射。

> **命题 12.3（商、核与第一同构的泛性质）**
>
> 在群范畴 `Grp` 中，`G/N` 是包含映射 `N → G` 与常值映射 `N → G` 的余等化子；`ker f` 是 `f` 与平凡同态的等化子。第一同构定理可以表述为：像分解 `G → G/ker f → im f` 中的比较映射是同构。

余等化子的泛性质就是定理 5.4：任何在 `N` 上取常值的同态都唯一地穿过 `G/N`。像分解把 `f` 写成满射接单射，比较映射的核与像分别给出单射与满射，因此是同构。

> **定理 12.4（米田引理与 Cayley 定理）**
>
> 从 `Hom(*, -)` 到自身的自然变换与 `G` 的元素一一对应；凯莱定理是它的特例。

## 13. 书目与读法

主读是 Dummit 与 Foote 的《Abstract Algebra》第 3 版第 1 至 6 章：

| 章 | 主题 | 关键结果 |
| --- | --- | --- |
| 1 | 群导引 | 群的定义、二面体群、对称群 |
| 2 | 子群 | 子群判别、循环群、生成元 |
| 3 | 商群与同态 | 正规子群、商群、同构定理 |
| 4 | 群作用 | 轨道、稳定子、Sylow 定理 |
| 5 | 直积与半直积 | 有限生成 Abel 群的基本定理 |
| 6 | 群论的进一步主题 | 可解群、幂零群、自由群 |

并行读物是 Fraleigh 与 Brand 的《A First Course in Abstract Algebra》第 8 版。前四部分为群与子群、群的结构、同态与商群、高级群论，例子多、习题偏计算，适合第一遍。

第 1 至 3 章连续读，商群依赖正规子群。第 4 章与第 6 章的 Sylow 部分可以合并。第 5 章的直积与半直积可以后置。

若目标是伽罗瓦理论，可解群与 Sylow 定理必须掌握。自由群与表现可以略读，等读到同调代数再回来。
