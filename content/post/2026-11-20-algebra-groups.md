群论研究对称性。对称性可以来自图形、置换或同余，抽象出来都是同一个结构：集合配上满足结合律、有单位元、有逆元的运算。本章先给三类例子，再建立子群、商群、作用与 Sylow 理论，最后到可解群与自由群。

## 0. 三个来源

正 `n` 边形的对称构成二面体群 `D_n`。旋转 `r` 生成 `n` 阶循环群，反射 `s` 满足 `s^2 = 1` 与 `srs^{-1} = r^{-1}`，合起来共 `2n` 个元素。

`n` 个文字的置换构成对称群 `S_n`，阶为 `n!`。每个置换可以分解为不相交轮换的乘积，符号同态 `sgn: S_n → {±1}` 的核是交错群 `A_n`。

模 `n` 的剩余类在加法下构成 `Z/nZ`；与 `n` 互素的剩余类在乘法下构成单位群 `(Z/nZ)^×`，阶为 `φ(n)`。

三类例子的共同点是：运算封闭、结合、有单位元、每个元素有逆元。把这四条抽出来，就是群的定义。若运算还满足交换律，称为 Abel 群。

## 1. 群、子群与循环群

群是集合 `G` 与二元运算 `·`，满足结合律、存在单位元 `e`、每个元素有逆元。群中元素个数称为阶，记作 `|G|`。

子群的判定只需要一条：非空子集 `H` 是子群，当且仅当对任意 `a, b ∈ H`，有 `ab^{-1} ∈ H`。这条判定同时覆盖了乘法封闭与逆元存在。

常见的子群包括：平凡子群 `{e}` 与 `G` 本身，`SL_n(F) ⊂ GL_n(F)`，`A_n ⊂ S_n`，以及整数加法群 `Z ⊂ Q`。

固定元素 `g`，反复相乘得到循环子群 `⟨g⟩ = {g^k : k ∈ Z}`。若 `g` 的某个正整数幂等于单位元，最小这样的正整数称为 `g` 的阶，此时 `|⟨g⟩|` 等于 `g` 的阶。

Lagrange 定理说，`|G| = |H|·[G:H]`，其中 `[G:H]` 是陪集的个数。证明只用一件事：左陪集 `gH` 构成 `G` 的划分，且每个陪集与 `H` 等势。

对有限群，由此得到两条常用推论。元素的阶整除群的阶；对任意 `a ∈ G`，有 `a^{|G|} = e`。取 `G = (Z/pZ)^×`，就得到费马小定理：`p` 为素数且 `p ∤ a` 时，`a^{p-1} ≡ 1 (mod p)`。

---

## 2. 正规子群与商群

子群不一定能作商。要使 `G/H` 上的乘法 `(gH)(hH) = ghH` 良定义，必须要求 `H` 满足 `gHg^{-1} = H` 对一切 `g` 成立。这样的子群称为正规子群，记作 `H ⊴ G`。

正规性有几个等价说法：左陪集与右陪集相同；`H` 是某个同态的核；`H` 在共轭作用下不变。

商群 `G/N` 的元素是陪集，运算由代表元相乘给出。良定义的关键正是正规性：换一个代表元，差一个 `N` 中的元素，商集里看不出区别。

群同态 `φ: G → H` 保持乘法。核 `ker φ` 是 `G` 的正规子群，像 `im φ` 是 `H` 的子群。第一同构定理给出

```text
G / ker φ ≅ im φ
```

证明分三步：定义 `g·ker φ ↦ φ(g)`，验证良定义、同态与双射。

对应定理进一步说，`G` 中包含 `N` 的子群与 `G/N` 的子群一一对应，正规子群对应正规子群。这条定理把「找商群的子群」化为「找原群中包含核的子群」。

三个标准例子：`Z → Z/nZ` 的核是 `nZ`；`sgn: S_n → {±1}` 的核是 `A_n`；`det: GL_n(F) → F^×` 的核是 `SL_n(F)`。

## 3. 群作用

群作用是把群元素实现为集合上的置换。形式地说，映射 `G × X → X`，记 `(g, x) ↦ g·x`，满足 `e·x = x` 与 `(gh)·x = g·(h·x)`。

等价的说法是同态 `G → Sym(X)`。群作用因此可以看成「群在某个具体对象上的像」，这比抽象地研究群更容易计算。

`x` 的轨道是 `Orb(x) = {g·x : g ∈ G}`，稳定子是 `Stab(x) = {g : g·x = x}`。轨道构成 `X` 的划分。

轨道-稳定子定理说

```text
|G| = |Orb(x)| · |Stab(x)|
```

证明用一个双射 `G/Stab(x) → Orb(x)`，`g·Stab(x) ↦ g·x`。这个定理把群论问题化成计数问题。

Burnside 引理把轨道的个数写成不动点的平均：

```text
|X/G| = (1/|G|) · Σ_{g∈G} |Fix(g)|
```

两个最重要的作用是正则作用与共轭作用。正则作用是 `G` 在自身上的左乘，凯莱定理由此得到：`G` 同构于 `S_G` 的一个子群。

共轭作用是 `g·x = gxg^{-1}`。轨道是共轭类，稳定子是中心化子 `C_G(x)`。把轨道-稳定子定理用于共轭作用，得到类方程

```text
|G| = |Z(G)| + Σ_i [G : C_G(x_i)]
```

其中 `x_i` 取遍非中心共轭类的代表元。类方程是证明「`p` 群中心非平凡」的标准工具。

## 4. Sylow 定理

设 `|G| = p^a m`，其中 `p` 为素数且 `p ∤ m`。阶为 `p^a` 的子群称为 Sylow `p`-子群。

Sylow 三定理：

- 存在性：Sylow `p`-子群存在。
- 共轭性：任意两个 Sylow `p`-子群共轭。
- 计数：Sylow `p`-子群的个数 `n_p` 满足 `n_p ≡ 1 (mod p)` 且 `n_p | m`。

计数条件是应用的重点。以 `|G| = 15` 为例，`n_3 | 5` 且 `n_3 ≡ 1 (mod 3)`，只能取 `n_3 = 1`；同理 `n_5 = 1`。两个 Sylow 子群都正规，交为平凡子群，所以 `G ≅ Z/3Z × Z/5Z ≅ Z/15Z`。

另一个常见用法是排除子群。`A_4` 的阶为 `12`，若它有阶 `6` 的子群，该子群指数为 `2`，因而正规。指数为 `2` 的正规子群包含所有平方元，而 `A_4` 中的 `3`-轮换都是平方元，共 `8` 个，超过 `6`，矛盾。

Sylow 定理给出存在性与计数，但不给出分类。有限单群的分类是另一件事，远超本章范围。

## 5. 可解群与幂零群

换位子 `[g, h] = ghg^{-1}h^{-1}` 衡量两个元素交换的程度。所有换位子生成的子群记作 `G' = [G, G]`，称为换位子群，它是正规子群，且 `G/G'` 是 `G` 最大的 Abel 商群。

从 `G` 出发，令 `G^{(0)} = G`，`G^{(i+1)} = [G^{(i)}, G^{(i)}]`，得到导列。若某一项等于平凡子群，称 `G` 可解。

可解性是伽罗瓦理论的判别条件：方程有根式解，当且仅当它的伽罗瓦群可解。`S_n` 在 `n ≤ 4` 时可解，`n ≥ 5` 时不可解，因为 `A_5` 是非交换单群，而 `S_n` 的可解性会传递到 `A_n`。

与可解性并列的是合成列。把 `G` 分解为单群的扩张，得到合成列；Jordan–Hölder 定理说，合成因子与排列顺序无关。有限群可解，当且仅当它的合成因子都是素数阶循环群。

幂零群的条件更强。令 `Z_0 = {e}`，`Z_{i+1}/Z_i = Z(G/Z_i)`，得到上中心列；若某一项等于 `G`，称 `G` 幂零。等价地，下中心列 `γ_1 = G`，`γ_{i+1} = [γ_i, G]` 最终到达平凡子群。

有限幂零群同构于其 Sylow 子群的直积。幂零群一定可解，反之不成立：`S_3` 可解，中心平凡，不是幂零群。

## 6. 自由群与表现

前面的群多由具体对象给出。自由群换一个方向：先给生成元，再允许所有可能的乘积，不加任何额外关系。

设 `S` 是集合，字母表取 `S ∪ S^{-1}`。由这些字母组成的有限串称为字，删除相邻的 `ss^{-1}` 与 `s^{-1}s` 后得到约化字。约化字在连接与约化下构成群 `F(S)`，称为 `S` 上的自由群。

自由群的泛性质：任意映射 `S → G` 都唯一延拓为同态 `F(S) → G`。这条性质说明自由群是「只受生成元约束」的群。

在自由群上再加关系，就得到群的表现：

```text
⟨S | R⟩ = F(S) / ⟨⟨R⟩⟩
```

其中 `⟨⟨R⟩⟩` 是 `R` 生成的正规子群。例如

```text
D_n = ⟨r, s | r^n = 1, s^2 = 1, srs = r^{-1}⟩
Z/nZ = ⟨x | x^n = 1⟩
Z^2 = ⟨a, b | aba^{-1}b^{-1} = 1⟩
```

表现把「构造群」变成「写生成元与关系」。代价是同一个群可以有无穷多种表现，判定两个表现是否给出同构的群一般不可解。

自由群的 Abel 化是自由 Abel 群：`F(S)^{ab} = F(S)/[F(S), F(S)] ≅ ⊕_{s∈S} Z`。这一步把自由群与线性代数接起来，也是同调代数的起点。

## 7. 范畴视角

把群 `G` 看成只有一个对象的范畴 `BG`：对象记作 `*`，态射是 `G` 的元素，复合是乘法。

`G` 在集合 `X` 上的作用就是一个函子 `BG → Set`。对象 `*` 映到 `X`，态射 `g` 映到置换 `x ↦ g·x`。函子保持复合与单位，对应的正是作用的结合律与单位元条件。

函子之间的自然变换就是 `G`-等变映射。轨道分解是集合的余积分解，稳定子刻画轨道的内部对称。

在这个语言下，凯莱定理可以看成米田引理的特例：把 `*` 的 Hom 函子作用在自身上，得到 `G` 在自身上的正则作用。

商群是包含映射 `N → G` 与常值映射的余等化子；同态的核是 `φ` 与平凡同态的等化子。这几个对应在后面几章会反复出现。

## 8. 书目与读法

主读是 Dummit 与 Foote 的《Abstract Algebra》第 3 版第 1 至 6 章：

| 章 | 主题 | 关键结果 |
| --- | --- | --- |
| 1 | 群导引 | 群的定义、二面体群、对称群 |
| 2 | 子群 | 子群判别、循环群、生成元 |
| 3 | 商群与同态 | 正规子群、商群、同构定理 |
| 4 | 群作用 | 轨道、稳定子、Burnside 引理 |
| 5 | 直积与半直积 | 有限生成 Abel 群的基本定理 |
| 6 | 群论的进一步主题 | Sylow 定理、可解群、幂零群、自由群 |

第 1 至 3 章连续读，商群依赖正规子群。第 4 章可以与第 6 章的 Sylow 部分合并。第 5 章的直积与半直积可以后置，等有限群的例子见得多一些再读。

并行读物是 Fraleigh 与 Brand 的《A First Course in Abstract Algebra》第 8 版，前四部分为群与子群、群的结构、同态与商群、高级群论。该书例子多、习题偏计算，适合第一遍。

若目标是伽罗瓦理论，第 4 章与第 6 章的可解群必须掌握，Sylow 定理至少要会用于小阶群的存在性与唯一性判定。自由群与表现可以略读，等读到同调代数再回来。
