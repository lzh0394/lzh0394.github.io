《抽象代数 I——代数学基础》由孟道骥、陈良云等编著，科学出版社 2010 年出版，前身是南开大学抽象代数课程改革所用的《代数学基础》。全书六章，依次处理基本概念、环、域、群、模与 Galois 理论，把群、环、模放在同一套同态语言下讲述。

教材在第一章就引入模，用同态基本定理统一描述三类结构的商；环论部分按唯一析因环、主理想整环、Euclid 环的层次组织因式分解；Galois 理论落在根式解与尺规作图两个经典问题上。本系列按三卷各自的目录逐章整理脉络与要点，本篇对应第一卷。

## 0. 三卷的定位

| 卷 | 主题 | 主要前置 | 使用场合 |
| --- | --- | --- | --- |
| I 代数学基础 | 群、环、域、模、Galois 理论 | 高等代数 | 本科必修 |
| II 结合代数 | 结合代数、张量积、Clifford 代数、群表示 | 第一卷与线性代数 | 本科选修、研究生 |
| III 交换代数 | 根式理想、诺特环、Dedekind 整环、维数、赋值 | 第一卷 | 研究生 |

三卷各自独立成书，难度与前置逐卷提高。第一卷给出通用语言，第二卷转向代数结构本身，第三卷进入交换代数与代数数论、代数几何的交界。三卷的目录合起来，就是这套教材对抽象代数主干的一次划分。

## 1. 基本概念

本章建立全书的语言：二元运算、同余关系、同态与商结构。定义顺序从幺半群到群，再并入环、域、模，最后用同态基本定理收束。

| 节 | 内容 |
| --- | --- |
| 1.1 | 二元运算与同余关系，商集的构造 |
| 1.2 | 幺半群与群，单位元、逆元与初等性质 |
| 1.3 | 子群与商群，陪集分解与正规子群 |
| 1.4 | 环与域，整环、除环、域的定义与例子 |
| 1.5 | 同态与同构，核与像 |
| 1.6 | 模，子模与商模 |
| 1.7 | 同态基本定理与同构定理 |
| 1.8 | 循环群及其分类 |

- 同余关系与正规子群、理想、子模一一对应，商结构由核决定。
- 模同时覆盖 Abel 群（`Z`-模）与线性空间（域上的模），后续两卷反复使用。
- 循环群给出第一个完整分类：无限循环群同构于 `Z`，`n` 阶循环群同构于 `Z/nZ`。

## 2. 环

本章围绕因式分解展开，从整环构造分式域，再逐个收紧条件：唯一析因环、主理想整环、Euclid 环。多项式环作为主要例子贯穿全章，最后用素理想与极大理想刻画商环。

| 节 | 内容 |
| --- | --- |
| 2.1 | 分式域，整环嵌入域 |
| 2.2 | 多项式环，次数与带余除法 |
| 2.3 | 对称多项式与对称多项式基本定理 |
| 2.4 | 唯一析因环，不可约元与素元 |
| 2.5 | 主理想整环与 Euclid 环 |
| 2.6 | 域上一元多项式与不可约判定 |
| 2.7 | 唯一析因环上的多项式环，Gauss 引理 |
| 2.8 | 素理想与极大理想 |

- 环的包含链为 Euclid 环蕴含主理想整环，主理想整环蕴含唯一析因环，反向均不成立。
- 分式域把整环嵌入域，是有理数域由整数环构造的推广。
- 素理想与极大理想把同态问题化为商环的类型判定，为第三卷的根式理想铺路。

---

## 3. 域

本章处理域扩张。从单扩张出发，用次数公式组织扩张塔，再引入分裂域、正规扩张与可分扩张，为 Galois 理论准备全部概念。最后一节给出代数基本定理的代数证明。

| 节 | 内容 |
| --- | --- |
| 3.1 | 域的单扩张，代数元与极小多项式 |
| 3.2 | 有限扩张与扩张次数的塔公式 |
| 3.3 | 分裂域与正规扩张 |
| 3.4 | 可分多项式与完备域 |
| 3.5 | 可分扩张与本原元素定理 |
| 3.6 | 代数学基本定理 |

- 单扩张把域扩张化为多项式环的商：`F(α) ≅ F[x]/(m_α(x))`。
- 正规性来自分裂域，可分性来自无重根，两者合起来给出 Galois 扩张。
- 本原元素定理说明有限可分扩张可由单个元素生成。

## 4. 群

本章从生成组与群作用出发，证明 Sylow 定理，讨论有限单群、直积、可解群与幂零群，并证明 Jordan–Hölder 定理。自由群一节用生成元与关系构造群，点群一节把群论用于三维对称性。

| 节 | 内容 |
| --- | --- |
| 4.1 | 群的生成组 |
| 4.2 | 群在集合上的作用，轨道与稳定子 |
| 4.3 | Sylow 子群与三条 Sylow 定理 |
| 4.4 | 有限单群，交错群的单性 |
| 4.5 | 群的直积与直积分解 |
| 4.6 | 可解群与幂零群 |
| 4.7 | Jordan–Hölder 定理 |
| 4.8 | 自由幺半群与自由群 |
| 4.9 | 点群 |

- 群作用把计数问题转为轨道计数，Sylow 定理由此得到。
- 可解群与幂零群分别对应导列与中心列，第 6 章用可解性判定根式解。
- Jordan–Hölder 定理说明有限群的合成因子与排列顺序无关。

---

## 5. 模

本章把线性空间的结构定理推广到主理想整环上的模，核心是有限生成模的分解定理。自由模、直和、扭模依次建立，最后落到矩阵标准形与有限生成 Abel 群的分类。

| 节 | 内容 |
| --- | --- |
| 5.1 | 自由模，基与秩 |
| 5.2 | 模的直和 |
| 5.3 | 主理想整环上的有限生成模 |
| 5.4 | 主理想整环上的有限生成扭模 |
| 5.5 | 有限生成模的应用 |
| 5.6 | 主理想整环上的矩阵与标准形 |

- 结构定理把有限生成模分解为自由部分与扭部分，扭部分再分解为准素循环模。
- 取 `R = Z` 得到有限生成 Abel 群的分类，取 `R = F[x]` 得到线性算子的有理标准形与 Jordan 标准形。
- 矩阵在左右乘可逆矩阵下的不变量由标准形给出。

---

## 6. Galois 理论

本章建立域扩张的 Galois 对应，把中间域与子群对应起来，然后用群的可解性判定方程根式解，用扩张次数判定尺规作图的可能性。

| 节 | 内容 |
| --- | --- |
| 6.1 | Galois 基本理论 |
| 6.2 | 一个方程的群 |
| 6.3 | 分圆域与二项方程 |
| 6.4 | 有限域 |
| 6.5 | 方程的根式解 |
| 6.6 | 圆规直尺作图 |

- Galois 对应是反序双射：中间域对应子群，正规扩张对应正规子群。
- 方程有根式解当且仅当 Galois 群可解，一般五次方程没有根式解。
- 尺规作图只允许二次扩张，三等分任意角、倍立方、化圆为方均不可作。

---

## 7. 读法建议

第 1 章是全书语言，宜先读完再进入后续章节。第 2 章与第 3 章连续阅读，环的因式分解直接服务于域上的不可约多项式。第 4 章的群论可独立阅读，但第 6 章同时依赖第 3 章的扩张理论与第 4 章的可解群。第 5 章的模论依赖主理想整环，宜放在第 2 章之后。

各节后的习题覆盖了正文未展开的例子，其中不少是后续卷的入口，例如自由模、正合序列与 Dedekind 整环。
