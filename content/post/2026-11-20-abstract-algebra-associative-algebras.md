《抽象代数 II——结合代数》由孟道骥等编著，科学出版社出版。第一卷是南开大学数学专业的必修课内容，本卷则是本科选修课与研究生的必修内容。全书五章，主题依次为结合代数、张量积与张量代数、二次型与 Clifford 代数、群代数及其表示、若干非结合代数。

本卷把第一卷中的环论平移到域上的代数，用模与表示的语言重新处理结构问题。张量积是贯穿全卷的工具，群表示与 Clifford 代数都建立在它之上。

## 0. 本卷定位

第一卷处理群、环、域、模的一般理论，本卷处理「域上带有双线性乘法的向量空间」，即代数。两者的区别在于：环的加法只是 Abel 群，代数的加法还是向量空间，因此可以使用基、维数、张量积与线性变换。

阅读本卷需要线性代数中的双线性型、特征值与特征向量，以及第一卷的模论与群论。第 4 章还需要有限群的基本结果，第 5 章与李代数、量子群等方向衔接。

| 章 | 主题 | 依赖 |
| --- | --- | --- |
| 1 | 结合代数的结构与表示 | 线性代数、模论 |
| 2 | 张量积与张量代数 | 线性代数 |
| 3 | 二次型与 Clifford 代数 | 第 2 章、双线性型 |
| 4 | 群代数与群表示 | 第 1、2 章、有限群 |
| 5 | 非结合代数 | 第 1、2 章 |

## 1. 结合代数

本章建立有限维结合代数的结构理论。先从定义与同态入手，再讨论表示、幂零性、幂等元与 Peirce 分解，最后证明半单代数与单代数的结构定理。

| 节 | 内容 |
| --- | --- |
| 1.1 | 结合代数的定义与例子 |
| 1.2 | 同态与同构 |
| 1.3 | 结合代数的表示 |
| 1.4 | 幂零结合代数 |
| 1.5 | 幂等元与 Peirce 分解 |
| 1.6 | 半单结合代数 |
| 1.7 | 单结合代数 |
| 1.8 | 体上的线性空间 |
| 1.9 | 半单结合代数的模 |

- 有限维半单结合代数同构于若干单代数的直积，单结合代数同构于体上的矩阵代数，这是 Wedderburn–Artin 结构定理的内容。
- Peirce 分解把幂等元对应的代数拆成四块，用于研究幂等元与模的分解。
- 表示把代数模写成线性变换，与第 4 章的群表示使用同一套语言。

## 2. 张量积与张量代数

本章引入张量积并用它构造新的代数。张量积的泛性质把双线性映射化为线性映射，张量代数、对称代数与外代数都是张量代数的商。

| 节 | 内容 |
| --- | --- |
| 2.1 | 线性空间的张量积 |
| 2.2 | 线性变换的张量积 |
| 2.3 | 张量与张量代数 |
| 2.4 | 对称张量与交错张量 |
| 2.5 | 对称代数与外代数 |
| 2.6 | 结合代数的张量积 |

- 张量积的维数等于因子维数之积，这一事实把多线性问题化为线性问题。
- 对称代数对应多项式代数，外代数给出行列式与微分形式的代数框架。
- 结合代数的张量积保持结合性，是构造群表示张量积与 Clifford 代数的基础。

## 3. 二次型与 Clifford 代数

本章从二次型出发，讨论正交群、四元数代数、Clifford 代数及其群。Clifford 代数把二次型编码进一个结合代数，使正交变换可以用代数元素表示。

| 节 | 内容 |
| --- | --- |
| 3.1 | 二次型 |
| 3.2 | 正交群 |
| 3.3 | 四元数代数 |
| 3.4 | Clifford 代数 |
| 3.5 | Clifford 群与旋量群 |

- 正交群由保持二次型的线性变换组成，反射生成正交群。
- 四元数代数同构于二维负定二次空间上的 Clifford 代数。
- 旋量群是 Clifford 群中范数为 1 的偶元素构成的子群，在实正定情形给出特殊正交群的双重覆盖。

## 4. 群代数及其表示

本章把有限群线性化。群代数以群元素为基，群表示等价于群代数上的模，特征标理论把表示的分类化为类函数上的正交关系。

| 节 | 内容 |
| --- | --- |
| 4.1 | 群代数的定义与基本性质 |
| 4.2 | 群表示的特征标 |
| 4.3 | 群代数中心的刻画 |
| 4.4 | 对称群的表示 |
| 4.5 | 群表示的张量积 |
| 4.6 | `p^a q^b` 阶群的可解性 |

- 当域的特征不整除群阶时，群代数是半单代数，这是 Maschke 定理的代数形式。
- 不可约特征标构成类函数空间的正交基，特征标的内积给出重数。
- 群代数的中心由共轭类的类和生成，其维数等于共轭类数，也等于不可约表示的个数。
- Burnside 定理断言 `p^a q^b` 阶群可解，证明使用群表示与特征标。

## 5. 某些非结合代数

本章放宽结合性，介绍几类重要的非结合代数。导子与包络代数把 Lie 代数嵌入结合代数，交错代数与 Jordan 代数分别来自八元数与对称算子，左对称代数与 Novikov 代数出现在数学物理中。

| 节 | 内容 |
| --- | --- |
| 5.1 | 代数与导子 |
| 5.2 | Lie 代数的包络代数 |
| 5.3 | 交错代数 |
| 5.4 | Jordan 代数 |
| 5.5 | 左对称代数与 Novikov 代数 |

- 导子是满足 Leibniz 律的线性映射，全体导子构成 Lie 代数。
- 包络代数把 Lie 括号实现为换位子，Poincaré–Birkhoff–Witt 定理给出它的基。
- 交错代数削弱结合性但保留柔性，八元数代数是典型例子；Jordan 代数的乘法交换但不结合。

## 6. 读法建议

第 1 章与第 2 章是全卷基础，第 3 章与第 4 章可以分别阅读，前者依赖张量积与二次型，后者依赖群论与半单性。第 5 章相对独立，适合在读完前四章后作为扩展。

本卷的习题中有不少计算性内容，例如低维代数的分类、四元数代数与矩阵代数的同构、对称群的特征标表，这些计算对理解结构定理的作用大于记忆定理本身。
